What is never pruned
  • The current Snapshot of every Instance, at any age — it is what every screen reads.
  • The newest {{.MinPerInstance}} Snapshot{{if ne .MinPerInstance 1}}s{{end}} of each Instance, so an Instance collected rarely still has something to compare against.
  • Both Snapshots of any drift comparison that found divergences — subject and baseline.
  • A job log while any of its Snapshots is still kept, and a Probe or Collection still running.
Pruning

A retention pass runs hourly inside the server — there is no separate job to schedule and no immediate delete when you save. Rows past their window are removed on the next pass, and the content-addressed file store is garbage-collected afterwards, so shared configuration is only dropped once the last Snapshot referencing it is gone.
