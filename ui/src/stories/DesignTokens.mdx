# Design tokens

Every value below is in `src/theme/theme.css`, lifted from the design file.
There is no theme object and no CSS variables — the wireframe uses literal hex,
so the app does too, and a diff against the design file stays readable. Treat
this page as the palette: if a colour is not here, it is not in the product.

## Type

Two families only: **Inter** for UI, **Roboto Mono** for anything that is data —
hostnames, paths, counts, timestamps, config text. If a value came out of a
config file or a database, it is mono.

| Role | Rule |
| --- | --- |
| Page title | `.h1` — 700 19px/1.2, `-.01em` |
| Panel title | `.ph2` — 600 12px |
| Body | 14px/1.4 Inter |
| Table | 12.5px, headers 600 10.5px mono uppercase `.06em` |
| Data | `.m` — 12px mono; `.mu` muted, `.mus` fainter |
| Section label | `.lbl` — 600 10.5px mono uppercase `.07em` |
| Badge | 600 10.5px mono `.03em` |

## Spacing, radius, elevation

| Token | Value | Where |
| --- | --- | --- |
| Page padding | `12px 16px` | `.bd` |
| Gap between panels | `10px` | `.row`, `.col`, `.bd` |
| Panel padding | `12px` | `.pnl` (`.pnl.z` is `0`; its header pads itself) |
| Control padding | `5px 9px` (small `3px 8px`) | `.fld`, `.sel`, `.btn` |
| Table cell | `5px 8px`, header `6px 8px` | `.t` |
| Radius | `3px` badge · `4px` control · `6px` panel | — |
| Elevation | `0 1px 2px rgba(0,0,0,.03)` | `.pnl` only; nothing else casts a shadow |
| Sidebar width | `210px` | `.nav` |

## Layout skeleton

```
.hdr        46px, fixed          logo · breadcrumb · search · avatar
.wrap       flex, min-height:0
  .nav      210px, scrolls
  .main     flex 1, scrolls
    .ptitle title + badges + actions
    .qbar    filters (optional)
    .bd      panels
```

`min-height: 0` on `.wrap` and `.main` is load-bearing: it is what makes a table
scroll inside its own panel instead of stretching the page.
